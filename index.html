Windows · Zalo PC

Mở nhiều tài khoản Zalo PC cùng lúc

Nhập tên các tài khoản, công cụ sẽ tạo sẵn file .bat. Mỗi tài khoản có một thư mục dữ liệu riêng nên các cửa sổ Zalo chạy song song, không đá nhau ra.

1. Cấu hình

Tài khoản phụ
Gõ tên có dấu cũng được, tên thư mục sẽ tự bỏ dấu.
Kiểu file
Mặc định đúng với đa số máy. Nếu khác: chuột phải shortcut Zalo → Open file location.

2. Sao chép mã

3. Lưu thành file và chạy

  1. Bấm Tải về để lưu thẳng file .bat, rồi chép file ra Desktop.
    Hoặc bấm Sao chép, dán vào Notepad, chọn File → Save As, mục Save as type chọn All Files và đặt tên đúng như trên khung code.
  2. Nhấp đúp file vừa lưu. Lần đầu, mỗi cửa sổ mới hiện mã QR, bạn quét bằng điện thoại của tài khoản tương ứng. Từ lần sau sẽ tự đăng nhập.
  3. Muốn có biểu tượng đẹp: chuột phải file → Send to → Desktop (create shortcut) → Properties → Change Icon → chọn Zalo.exe.
Đăng xuất / xóa một tài khoản phụ: xóa thư mục tương ứng trong . Nếu Windows SmartScreen cảnh báo khi chạy file .bat, bấm More info → Run anyway; bạn có thể mở file bằng Notepad để kiểm tra, nội dung chỉ là các lệnh ở trên.
